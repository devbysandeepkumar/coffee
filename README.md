# ☕ Coffee — Interactive Coffee Showcase

A sleek, dark-themed modern web application built with **React**, **Tailwind CSS**, and **React Icons**. Features full-page vertical scroll snapping, fixed sidebar index indicators, and a modern presentation-style user interface.

![Tailwind CSS](https://img.shields.io/badge/Tailwind_CSS-38B2AC?style=for-the-badge&logo=tailwind-css&logoColor=white)
![Vite](https://img.shields.io/badge/Vite-646CFF?style=for-the-badge&logo=vite&logoColor=white)

---

## ✨ Features

- 🎯 **Full-Page Vertical Scroll Snap**: Presentation-style smooth scrolling that locks cleanly onto each coffee item.
- 📌 **Fixed Sidebar Navigation**: A left-hand index column (`01`, `02`, `03`) that stays pinned while content scrolls.
- 🎨 **Modern Dark UI**: Aesthetic dark theme built with `#1B222C`, styled with custom Tailwind utilities and Google Fonts (`Poppins`).
- ⚡ **Optimized Asset Delivery**: Static assets loaded efficiently from the `/public` directory.
- 📱 **Clean Layout**: Fixed layout architecture separating header, fixed index controls, and scrollable product details.

---

## 🛠️ Tech Stack

- **Framework**: [React](https://reactjs.org/)
- **Build Tool**: [Vite](https://vitejs.dev/)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
